# 🚢 Анализ движения судов по данным АИС

## О проекте

Проект выполнен в рамках хакатона по анализу данных. Мы проанализировали реальные записи АИС (Automatic Identification System) — данные о движении судов: координаты, скорость, курс, временные метки и качество сигнала.

**Задачи:**
- Очистить сырые данные от ошибок и выбросов
- Рассчитать пройденные расстояния и другие метрики для каждого судна
- Построить графики и интерактивные карты
- Создать дашборд для удобного просмотра результатов

## Как запустить проект

Чтобы запустить проект, нужно выполнить несколько шагов.

**Шаг 1. Установите Python**  
Скачайте и установите Python версии 3.9 или выше с официального сайта python.org.

**Шаг 2. Скачайте проект**  
Скопируйте папку `hakaton_project` на свой компьютер.

**Шаг 3. Установите библиотеки**  
Откройте терминал или командную строку в папке `hakaton_project` и выполните команду:

pip install -r requirements.txt

Эта команда установит все необходимые библиотеки.

**Шаг 4. Запустите дашборд**  
Выполните команду:
streamlit run dashboard/app.py

**Шаг 5. Откройте в браузере**  
Перейдите по адресу `http://localhost:8501`. Вы увидите интерактивный дашборд.

**Примечание:** Если команда `streamlit` не работает, попробуйте альтернативный запуск:
python -m streamlit run dashboard/app.py

**Как посмотреть графики и карту:**

- Откройте папку `plots` — там лежат все сгенерированные графики
- Откройте файл `maps/tracks.html` в браузере — увидите интерактивную карту треков
- Откройте папку `barplot` — там находятся столбчатые диаграммы

## Структура проекта

Папка `data` — содержит очищенные данные `clean_data.csv`.

Папка `metrics` — содержит файл с метриками `metrics_per_ship.csv`.

Папка `dashboard` — содержит файл дашборда `app.py`.

Папка `plots` — содержит все сгенерированные графики.

Папка `maps` — содержит интерактивную карту `tracks.html`.

Папка `barplot` — содержит столбчатые диаграммы `Figure_1.png` и `Figure_2.png`.

В корне проекта также лежат все скрипты участников: `boxplot.py`, `anomaly.py`, `clean_ais_data.py`, `plot_tracks.py`, `visualization.py`. А также файлы `requirements.txt` и `README.md`.
